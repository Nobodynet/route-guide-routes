# route-guide-routes

버스 노선 길잡이 앱이 내려받는 서울·경기 버스 노선 데이터(정류장 순서·경로선)입니다.
매주 자동으로 갱신됩니다.

- `current` 릴리스의 `routes_manifest.json` — 노선 목록과 묶음 파일 주소 (항상 최신)
- `packs-YYYYMMDDHHMM` 릴리스 — 지역별 노선 묶음 (`*.routes.json.gz`)

## 출처

- 서울특별시 버스 노선 정보: 서울특별시, 「서울특별시_노선정보조회 서비스」(공공데이터포털),
  [공공누리 제1유형(출처표시)](https://www.kogl.or.kr/info/licenseType1.do)
- 경기도 버스 노선 정보: 경기도, 「경기도_버스노선 조회」(공공데이터포털), 이용허락범위 제한 없음

원 데이터를 정류장 순서·경로선 형식으로 바꾸고 검증한 것이며, 실제 운행과 다를 수 있습니다.
